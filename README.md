# Koffie-bot

A versatile Discord bot built with JavaScript to enhance server management and user experience.

![GitHub stars](https://img.shields.io/github/stars/TomMhee/Koffie-bot?style=social)
![GitHub forks](https://img.shields.io/github/forks/TomMhee/Koffie-bot?style=social)
![GitHub issues](https://img.shields.io/github/issues/TomMhee/Koffie-bot)

## Features

- 🔊 **Voice Channel Management**: Create temporary channels, music playback
- 🔐 **Moderation Tools**: Message filtering, user timeout, role management
- 🎮 **Server Games**: Interactive mini-games to boost community engagement
- 📊 **Analytics**: Track server activity and member engagement

## Tech Stack

- JavaScript/Node.js
- Discord.js
- MongoDB for data persistence
- Docker for containerization

## Installation

```bash
# Clone the repository
git clone https://github.com/TomMhee/Koffie-bot.git

# Navigate to project directory
cd Koffie-bot

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
# Edit .env with your Discord bot token and other settings

# Start the bot
npm run start
```

## Usage

Once installed and configured, invite the bot to your server using the OAuth2 URL. 
Use `!help` to see all available commands.
